# ХАССП-ПРОФИ — сайт-визитка

Готовый статический сайт (один файл `index.html`). Публикация на Vercel — без домена, бесплатно, 5–10 минут.

## Способ А. Без GitHub, через Vercel CLI (проще всего)

1. Установите Node.js (nodejs.org), если ещё не установлен.
2. Скачайте и распакуйте этот архив себе на компьютер.
3. Откройте терминал (командную строку) в папке с распакованными файлами.
4. Выполните:
   ```
   npx vercel
   ```
5. Впервые Vercel попросит войти — откроется браузер, войдите через email или GitHub.
6. На вопросы отвечайте по умолчанию (просто Enter), в конце получите адрес вида:
   ```
   https://haccp-profi-xxxx.vercel.app
   ```
7. Чтобы адрес был покороче и постоянным, выполните ещё раз:
   ```
   npx vercel --prod
   ```
   и в панели Vercel (vercel.com → ваш проект → Settings → Domains) задайте свой бесплатный поддомен, например `haccp-profi.vercel.app`.

## Способ Б. Через GitHub (если хотите, чтобы Claude или кто-то ещё позже мог легко обновлять сайт)

1. Создайте аккаунт на github.com (бесплатно) и на vercel.com (бесплатно, можно войти через GitHub).
2. На GitHub нажмите **New repository**, назовите, например, `haccp-profi`, оставьте Public или Private — не важно.
3. Загрузите файлы этого архива в репозиторий (кнопка **Add file → Upload files**, перетащите всё содержимое папки).
4. Зайдите на vercel.com → **Add New → Project** → выберите этот репозиторий → **Deploy**.
5. Через 30–60 секунд Vercel выдаст ссылку вида `haccp-profi.vercel.app` — сайт уже работает.
6. Дальше при любом изменении файлов на GitHub Vercel будет пересобирать сайт автоматически.

## Что внутри

- `index.html` — весь сайт одним файлом (стили, фото в base64, все секции и кнопки уже внутри, ничего докачивать не нужно).
- `vercel.json` — настройки публикации (чистые ссылки, заголовки безопасности).
- `robots.txt` — разрешает индексацию поисковикам.

## После публикации

- Ссылку можно будет разослать клиентам, указать в VK/Telegram/Avito.
- Свой домен (например, `хассп-профи.рф`) можно подключить позже в любой момент — в Vercel: Settings → Domains → Add. Текущий бесплатный поддомен `*.vercel.app` при этом продолжит работать.
- Если понадобится изменить текст, цены или фото — пришлите правки, я обновлю `index.html`, и вам останется просто загрузить обновлённый файл заново (способ А — `npx vercel --prod`, способ Б — заменить файл на GitHub).
